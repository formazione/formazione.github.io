Online collaboration setup

This version synchronizes the board through Firebase Realtime Database. The Firebase configuration is already included. Everyone opening the same board link will edit the same map.

Firebase Realtime Database rules must permit reads/writes for collaborators. For a public classroom board, add authentication/security rules before sharing widely. Images are stored as compressed data inside board items, so keep pasted images reasonably small.
